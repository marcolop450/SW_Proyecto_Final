## Decisions

Usar una copia limpia del commit publicado para repetir la guía con variables privadas y comprobaciones de solo lectura. La reproducción en otro equipo requiere la participación de un integrante. La propuesta de AWS usa una sola VM con la base en Supabase y conserva el plan gratuito. Las imágenes se construyen fuera de la VM para reducir memoria y disco de compilación en AWS.

## Hook de Reajuste

La etapa de publicación concreta región, DNS, responsable, tiempo de demo y presupuesto antes de crear recursos. La verificación final se realiza desde la URL pública.
