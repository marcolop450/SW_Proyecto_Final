# Recuperación y seguimiento de teletrabajo

La jornada se inicia y finaliza cuando la API confirma la operación. Las sesiones activas se recuperan al abrir el módulo y el servidor recibe avances periódicos. Las pausas se registran al terminar con su duración real; una pausa activa se conserva en el navegador para recuperarla.

El seguimiento de actividad describe interacción con la página, no productividad. La presencia se indica como no disponible hasta recibir una detección. La conexión de la jornada envía latidos al mosaico.
